   keeps the input's dry ports, as `candidates` had `dryPorts`

   every camera candidate. `build` maps with `b.ports`, as before.

   `internal/selection`: the e2e tests import them, and the bridge's layer
   no longer does.

   (`internal/nodes/nodes.go:46, 66`, `fabricui.DefaultNodeKey`, since
   U6b), which the brief's facts did not list.

   provider was still in the bridge.
