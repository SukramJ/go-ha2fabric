## Differences from the brief

1. No "switch without a target": 0.7.1 panics on `Set(nil)`, so the
   configured node's status reads the stopped node (above), and the tests
   assert that.
2. The 500's problem body has no error detail (`serverError`,
   `problem.go:69-73` at v0.7.1). The test asserts the sentinel in the
   log instead.
3. `ha2fabric.node_erased` is logged before the come-back, so `fabrics
   count=0` and `pairing` follow it (§6's order, not §3's pseudocode). It
   is logged only when a reset ran, and at warn with `error` when the
   reset failed.
4. `running()` is an atomic mirror, so `List` does not wait on an erase
   (§3 "Concurrency").
5. `fleet.Warnings` prefixes every warning of a registry node, so a
   registry node's `selection_corrupt` now shows too. Before, it showed
   nowhere.
6. U8's "Hosts" text has the fleet keep the raw `*node.Node`. The brief's
   Decided 1 has the switch, and I followed the brief.

## Decisions

- Mine: `Resync` without a run returns nil (the next run applies the
  selection); `fleet.Erase` of a member that never started returns an
  error (unreachable: its route answers 503).
