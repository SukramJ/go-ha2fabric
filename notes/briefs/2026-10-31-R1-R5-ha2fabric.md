## 2. internal/adapt — commands (command.go:34-134)

Extend `Service(cmd, cur)`; every case cites the HA service and its
data key from `read-r1r5-ha-core.md`:

| domain | method (go-hamapping constant) | payload | call |
| --- | --- | --- | --- |
| button | press | any | `button.press` |
| select | select_option | option string | `select.select_option {option}` |
| climate | preset_mode | name | `climate.set_preset_mode {preset_mode}` (fan already uses MethodPresetMode → `set_preset_mode`; the climate case is a new branch) |
| climate | fan_mode | name | `climate.set_fan_mode {fan_mode}` |
| climate | turn_on / turn_off | – | `climate.turn_on` / `climate.turn_off` |
| vacuum | run_mode | "0" / "1" | `vacuum.return_to_base` / `vacuum.start` |
| vacuum | pause / resume / go_home | – | `vacuum.pause` / `vacuum.start` / `vacuum.return_to_base` |
| valve | open_valve / close_valve | – | `valve.open_valve` / `valve.close_valve` |
| water_heater | operation_mode | "off" / "on" | off → `water_heater.set_operation_mode {operation_mode: "off"}`; on → `water_heater.turn_on` when the ON_OFF bit (8) is in `supported_features`, else `set_operation_mode` with the first entry of `cur.Attributes.operation_list` that is not "off" (ErrCommand when none) |
| water_heater | temperature | number | `water_heater.set_temperature {temperature}` |
| media_player | turn_on / turn_off | – | `media_player.turn_on` / `turn_off` |
| media_player | volume_mute | "true"/"false" | `media_player.volume_mute {is_volume_muted}` |
| media_player | volume_level | 0..254 | `media_player.volume_set {volume_level: round(level/254, 2)}` |
| media_player | media_play / media_pause / media_stop | – | the service of the same name |
| media_player | key | 65 / 66 / 67 / 64 | `volume_up` / `volume_down` / `volume_mute {is_volume_muted: !cur.is_volume_muted}` / `media_player.toggle`; any other code → ErrCommand |

If go-hamapping's final method names differ from this table, the
constants win; list the difference in the hand-back.
